# Changelog - История изменений TwitchService

Все значимые изменения в проекте документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Добавлено

- Метод для удаления старой глобальной переменной `twitch_todays_viewers`.
- Метод для удаления устаревшей глобальной переменной `twitchLastViewersNameList`

### Изменено

- Глобальная переменная `twitch_todays_viewers` изменена на `twitchTodaysViewers`

### Удалено
 - Метод получения списка ников текущих зрителей в отдельную глобальную переменную.

### Производительность

- Вынес из цикла запись глобальной переменной со списком зрителей.

## [1.1.0] - 2025-01-09

### Добавлено

- Метод получения списка ников текущих зрителей в отдельную глобальную переменную.


## [1.0.3] - 2024-09-09

### Добавлено

- Метод получения новых зрителей.
- Метод игнорирования зрителей, написавших в чат, до пометки их новыми.

## Формат версионирования

- **MAJOR.MINOR.PATCH**
- **MAJOR** - несовместимые изменения API
- **MINOR** - новая функциональность (обратно совместимо)
- **PATCH** - исправления багов (обратно совместимо)
