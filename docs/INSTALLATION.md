# TwitchService - Руководство по установке и настройке

## Disclamer
На данный момент я не рекомендую пользоваться версией 1.0.0 стримербота, так как имеются проблемы работы интеграции с миничатом с этой версией.

## Шаг 1: установка
1. Скачайте файл `TwitchService.txt` из последнего релиза.
2. Запустите стримербот.
3. В верхнем меню нажмите кнопку `Import`.
![](./images/import_btn.png)
3. Перетащите скачанный ранее `TwitchService.txt` в область `Import String`. Если перетащить не получается, откройте файл блокнотом, скопируйте текст и вставьте его в `Import String`.
